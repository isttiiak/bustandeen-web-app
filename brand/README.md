# Bustandeen brand files

Not part of the app build. Regenerate everything with `npm run brand:assets --prefix frontend`
(geometry and colours: `frontend/src/brand/brandMark.ts`).

| File                          | Use                                                   |
| ----------------------------- | ----------------------------------------------------- |
| `mark.svg`                    | Master logo, transparent, Bright colours              |
| `mark-small.svg`              | One-flower version for 16-40 px                       |
| `mark-on-light.svg`           | Darker colours for light backgrounds                  |
| `profile.svg`                 | Logo on its dark tile (master for the profile photos) |
| `profile-1080-instagram.png`  | Instagram                                             |
| `profile-720-facebook.png`    | Facebook page                                         |
| `profile-512-email.png`       | Zoho Mail / Google account sender photo               |
| `profile-400-x-linkedin.png`  | X and LinkedIn                                        |
| `profile-256-reddit.png`      | Reddit                                                |
| `cover-facebook-1640x924.png` | Facebook cover (text stays in the band desktop shows) |
| `cover-x-1500x500.png`        | X header                                              |
| `cover-reddit-1920x384.png`   | Reddit banner                                         |
| `cover-linkedin-1128x191.png` | LinkedIn cover                                        |

Profile photos keep the logo inside the circle every platform crops to.
