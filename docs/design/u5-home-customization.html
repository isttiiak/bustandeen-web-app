3 · Home (live result)

  1. Both phones edit one state: the setup only preselects, Settings changes it later. Turning a quick section off never touches the habit's data, goal or order.
  2. Salat's quick section is the prayer timeline. With it off, "Adhkār on the timeline" is greyed out (Home has no other place for the adhkār card).
  3. Goal rows have their own order (it starts as the habit order). At least one row while the card is on. Unticking the last row is blocked with a hint, not a silent switch-off.
  4. Synced prefs: existing bustandeen_home_sections_off + bustandeen_home_timeline (kept), new bustandeen_home_goals (JSON: on, row order, rows off, badges). If a sync ever lands on "nothing on", Home shows the goals card.
