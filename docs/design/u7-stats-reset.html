U7 Stats fresh start (prototype)

A reset never deletes anything. It stores a start date per area (like today's salat reset). Totals, streaks and averages count from that date; history, calendars and day logs still show every day, with a small "Fresh start" marker. Obligations (Kaza debt, qaḍāʾ fasts, kaffārah, vows) and memorised āyāt are never touched by a stats reset.

      How it works

      • One start date per area on the account (salat keeps its existing salatResetDate and history, so old salat resets carry over). The date is today's tracking day (Fajr / midnight / Maghrib setting).
      • Undo: the most recent reset of an area can be undone at any time (it only moves the date back). Each reset is kept in a small list with its optional note, like the salat Journey phases.
      • "Reset all stats" = one confirm, same date for every area in the table.
      • The old zikr "Reset counters" (zeroes lifetime totals, deletes the goal) and Quran "Reset reading counts" (clears surah counts) are replaced by this, so no reset is destructive any more.
      • Every reset and correction is in the backup file (U6), so a restore brings the same view back.
