bayan.bustandeen.com: Help & Updates

Prototype for approval. One static, prerendered site (like the SEO pages: no app bundle, no sign-in, no service worker), dark only, English and Bangla. Four parts: Guides, What's new, How we calculate, Credits. help.bustandeen.com 301s here. Pick a page and a language; the desktop and phone frames show the same page.

How it is built (once approved)

  • Same pipeline as the SEO pages: new templates in src/seo/templates/bayan/, rendered by entry-server.tsx + prerender.mjs into dist/bayan/**, hydrated by static-entry.ts only for the language switch and the search box. No React app, no Firebase, no API call.
  • Hosting: Vercel rewrite on host bayan.bustandeen.com: /(.*) → /bayan/$1; Bangla at /bn/... on that host. help.bustandeen.com/* → 301 bayan.bustandeen.com/*. On bustandeen.com, /bayan/* 301s to the subdomain so there is one canonical URL. Own sitemap, hreflang en/bn, canonical on every page.
  • Content source: guides and "How we calculate" are TSX content files in en + bn (reviewed like any copy). "What's new" is written per release in plain words, not the raw CHANGELOG (that one is for developers); the last ~12 releases, newest first. The app's About page and footer link here ("Help & updates").
  • Religious content: "How we calculate" only states what the app does and which rule source it follows. No rulings, no new Quran or hadith text; anything quoted later is verified with its number and grade first.
  • First set of guides (8): Getting started, Salat and kaza, Fasting and make-up days, Zikr counter and goals, Quran habit, khatam and hifz, Musafir (travel prayer), Rayhanah privacy, Friends and Noor privacy. Screenshots are added later (placeholders now).
  • Not in scope: search beyond the page titles (a small on-page filter only), comments, sign-in, any third-party script. Analytics: none on bayan for now.
