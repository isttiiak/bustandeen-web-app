Explore freely, sign in to save

U10 prototype. Everything stays open to look at. Reading and reference (Quran, prayer times, Qibla, Musafir, duas) never ask for anything. The first time someone saves a record, a calm sheet explains why an account helps. No lock icons, no "required". Tap the buttons in the frames: they work.

What stays open, what asks

  • Never asks: Quran read and listen, prayer times, Qibla, Musafir, special days, sadaqah, all SEO pages, device-only settings (language, theme, prayer method).
  • Asks on the first save (sheet, frame 1): Salat, Fasting, Ramadan, Quran habit, khatam, hifz, bookmarks.
  • Never interrupts (frame 2): the zikr counter. Counts carry through sign-in on the same browser.
  • Preview gate (frame 3): every analytics page, Profile, the rest of Settings.
  • View only (frames 4, 5): Rayhanah, Friends. Naseeh stays hidden for guests.

Notes for the build

  • One shared SignInSheet (title + reason per feature) replaces SalatGuestDialog, FastingGuestDialog and ZikrGuestDialog; one PreviewGate replaces the lock card in Protected.
  • Both buttons keep the current return path (bustandeen_redirect), so after sign-in the person lands back on the same page.
  • Copy in English and Bangla, calm wording, no em dashes. Tap targets 44px (the e2e check).
  • Demo stays in the code: reached from "See an example" (frame 3) and still used by CI.
